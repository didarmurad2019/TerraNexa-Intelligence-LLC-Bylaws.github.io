# TerraNexa Intelligence, LLC — Bylaws Website
Static site for GitHub Pages (no build step).
## Deploy
1. Upload all files in this folder to the `main` branch of repo `TerraNexa-Intelligence-LLC.github.io`.
2. Settings → Pages → Deploy from branch → `main` / root.
## Maintain
- Text: edit the `A` array (articles) and `R` (reserved matters) in `assets/js/app.js`.
- Official PDF: replace `assets/docs/TerraNexa-Bylaws.pdf` (keep the filename).
- Images: `assets/img/*.svg`. Colors: CSS variables at top of `assets/css/style.css`.
- Update the version number in the hero of `index.html` when the Bylaws are amended.
