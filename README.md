# TerraNexa Intelligence, LLC – Bylaws Website
Static site for GitHub Pages: https://didarmurad2019.github.io/TerraNexa-Intelligence-LLC.github.io/
## Deploy
Upload everything in this folder to the repository root (branch `main`), then Settings → Pages → Deploy from branch → main / root.
## Maintain
- Edit `docs/bylaws.md` (the site renders it automatically).
- Run `python build_pdf.py` to regenerate the PDF.
- Replace every [Placeholder] (state, address, dates) before publishing.
- "Create PDF / Print" uses the browser's Save-as-PDF with print styling.
